# Abhi Adusumilli — Portfolio

Personal portfolio site for Abhinav Krishna Adusumilli — Penn State data science student pursuing
roles in consulting, banking, and data / business analytics.

Static site (HTML/CSS/vanilla JS), deployed via GitHub Pages.

## Structure

- `index.html` — page content
- `styles.css` — styling
- `script.js` — mobile nav, scroll-spy, back-to-top, and scroll reveal
- `assets/` — headshot and downloadable résumé PDF

## Local preview

```
python3 -m http.server 8080
```

Then open http://localhost:8080
